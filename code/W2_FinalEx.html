Introduction

The goal of this exercise is to wrangle extremely messy data, and produce a final clean dataset and figure on the Ross River estuary fish surveys. The data are from a previous PhD student who conducted surveys over 30 days in May 2026 at four different sites along the Ross River estuary, Townsville, Queensland, Australia. The data include catch counts for four different fish species, as well as environmental data (temperature, salinity, and turbidity) collected at each site using sonde sensors.

Notes on sensor data

Sensor data includes 15-minute sonde data for the same 4 sites and 30 days of sampling. The sourced script above turned this into daily data and removed outliers. There are three different environmental variables measured: temperature, salinity, and turbidity. We could investigate the effects of all three on fish species abundance or pick one… Let’s remember that the goal of this exercise is to produce a publication-ready visualisation of the estuary’s ecology.

The sensor data is now in a dataframe called sensor_daily, which has the following variables: site, date, mean_temp, mean_salinity, and mean_turbidity. We can join this with the catch data and metadata to create a final dataset for analysis.

Wrangle final dataset

catch_data_final <-

earth_cols <- c(
"#D8B365", # sand
"#8C6D46", # brown
"#5A7D5A", # sage
"#4F7A8A" # muted blue-grey
)

earth_cols_dark <- c(
"#B08E45",
"#6B5231",
"#416041",
"#365765"
)

fish_stats |> 
  ggplot(aes(x = zone, 
             y = mean_catch, 
             fill = scientific_name, 
             colour = scientific_name)) +
  geom_line(group = 1) +
  # add in points from master data
  geom_point(
    data = catch_data_final, 
    aes(x = zone, 
        y = count, 
        colour = scientific_name),
    position = position_jitter(width = 0.2), 
    alpha = 0.4, 
    size = 1.5, 
    inherit.aes = FALSE) + 
  geom_point(
    position = "dodge", 
    size = 5, 
    pch = 23,
    colour = "black") +
  scale_fill_manual(values = earth_cols) +
  scale_colour_manual(values = earth_cols_dark) +
  # SE pretty narrow, potentially not worth plotting but let's viewer see that included
  geom_errorbar(aes(ymin = mean_catch - sem_catch, ymax = mean_catch + sem_catch), 
                position = position_dodge(0.9), width = 0.2) + 
  facet_wrap(~ scientific_name, scales = "fixed") +
  marine_theme +
  theme(
    strip.text = element_text(face = "italic", size = 12, colour = "black"), # spp names in italic
   # legend.position = "bottom"
    legend.position = "none" # legend unnecessary
  ) +
  labs(
    x = "Spatial Zone",
    # scientific label for y axis of n day -1 use regex to get superscript
    y = expression("Abundance (n day"^-1*")"),
  #  y = "Daily abundance (n day^-1)"
    y = "Abundance (per day)"
  )
